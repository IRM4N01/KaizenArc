# Training Arc 🏋️

A personal gym tracking web app built with HTML, CSS, and vanilla JavaScript.

## About

Training Arc is a workout planner and tracker designed for lifters who follow structured programs. It lets you track your 1RM personal bests for the four main compound lifts, view automatic percentage breakdowns, and plan your training program day by day.

## Features

- 📊 Track 1RM personal bests for Bench Press, Squat, Deadlift, and Overhead Press
- 💯 Automatic percentage breakdowns based on your 1RM
- 📋 Create training programs with custom workout days
- 💾 Data saved locally in the browser — no account needed

## Built With

- HTML
- CSS
- JavaScript (vanilla)
- localStorage for data persistence

## How To Run

1. Clone or download the repository
2. Open `index.html` in your browser
3. No installations or dependencies required
